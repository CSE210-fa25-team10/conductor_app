# PRODUCTION NOTES & SPECIFICATIONS

## Color Palette
- **Primary Blue**: #0066CC (professional, tech-forward)
- **Accent Green**: #00AA44 (trust, positive outcomes)
- **Warning Red**: #DD3333 (urgency, problems being solved)
- **Dark Gray**: #333333 (text, contrast)
- **Light Gray**: #F5F5F5 (backgrounds)
- **White**: #FFFFFF (clean, modern)

## Typography
- **Headlines**: Bold, sans-serif (e.g., Montserrat Bold, 48px)
- **Body Text**: Regular sans-serif (e.g., Open Sans, 18px)
- **Callouts**: Medium weight, 14-16px

## Animation Style
- **Transitions**: Smooth 0.3–0.5s fade/slide transitions
- **Emphasis**: Subtle bounces, glows, scale-ups (never jarring)
- **Icons**: Line animations (drawing effect) for key elements
- **Counters**: Animated number incrementing (1, 2, 3…)

## Music & Sound Design
- **Intro (0:00–0:35)**: Upbeat, modern electronic music (builds energy)
- **Feature Demo (0:35–2:05)**: Energetic background music with purposeful transitions
- **Benefits (2:05–2:40)**: Orchestral, uplifting score
- **CTA (2:40–3:00)**: Dramatic orchestral crescendo, fades to silence
- **Sound Effects**: Subtle confirmation beeps, transition whooshes (NOT overwhelming)

## Video Format
- **Resolution**: 1080p (1920×1080) minimum, preferably 4K (3840×2160)
- **Frame Rate**: 24fps (cinematic) or 30fps (modern web)
- **Aspect Ratio**: 16:9 (widescreen, YouTube/LinkedIn standard)
- **File Format**: MP4 (H.264 codec for universal compatibility)

## Voiceover Requirements
- **Gender**: Your choice (suggest diverse representation if possible)
- **Tone**: Enthusiastic but professional, confident, relatable
- **Pacing**: Moderate speed, clear enunciation, natural delivery
- **Recording Quality**: Clean audio, no background noise, professional microphone
- **Post-Processing**: Light compression, EQ to remove harshness

# SCREEN RECORDING TIPS

### For Dashboard Screenshots:
- Use real or high-fidelity mockup data (realistic names, numbers)
- Ensure UI is pixel-perfect, no errors or unfinished elements
- Test all screen sizes (if recording live demo)
- Use consistent browser zoom (100%)
- Disable notifications, emails, chat to avoid distractions

### For Mobile Views:
- Use iPhone mockup frame (or Samsung if showing Android)
- Mock up screens in Figma or Adobe XD
- Ensure text is readable at video size
- Show actual touch interactions (fingers tapping, swiping)

### Recording Environment:
- Clean, professional lighting
- No background distractions (keep behind you neutral)
- Use stable camera/screen recording setup (no shaky footage)
- Test audio levels before full recording
