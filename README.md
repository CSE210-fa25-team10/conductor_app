# Conductor

CSE210 --- Team 10.

Conductor is a lightweight web application to facilitate the operation of an undergraduate software engineering course.

## Install

Clone the repository, and enter the project.
```
git clone https://github.com/CSE210-fa25-team10/conductor_app.git
cd conductor_app
```

## Usage

Starting the Conductor server:
```
docker compose up -d
```

Stopping the Conductor server:
```
docker compose down
```
