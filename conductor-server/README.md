# Conductor Server

A lightweight Node.js + Express 5.1.0 backend for the Conductor Tool project.

## 🚀 Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Run the server

```bash
npm start
```

The server will start at:

```
http://localhost:3000
```

You should see:

```angular2html
✅ Express 5.1.0 server running on Node.js v24.11.0 LTS
```
