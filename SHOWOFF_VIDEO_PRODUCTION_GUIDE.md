## VOICEOVER PRODUCTION CHECKLIST

### Pre-Recording:
- [ ] Script reviewed and approved
- [ ] Voiceover talent hired or assigned
- [ ] Recording booth or quiet room reserved
- [ ] Microphone tested and calibrated
- [ ] Audio interface levels set (-12dB to -6dB range)
- [ ] Pop filter installed to reduce plosives
- [ ] Backup recording device ready

### Recording Session:
- [ ] Do 2–3 takes of full script
- [ ] Record individual sentence takes for flexibility
- [ ] Vary emphasis on key phrases ("cuts admin work by 70%", "orchestrating success")
- [ ] Record in natural pauses where slides will change
- [ ] Save files with clear naming (Conductor_VO_Take1, etc.)

### Post-Production:
- [ ] Normalize audio to -3dB
- [ ] Remove background noise (gentle gate or noise reduction)
- [ ] EQ slightly (reduce harsh sibilants around 5-8kHz)
- [ ] Compress slightly for consistent levels
- [ ] Export as WAV or high-quality MP3 for editing

## VIDEO EDITING WORKFLOW

### Step 1: Organize Assets
- Create folder structure: /Raw_Video, /Audio, /Graphics, /Music, /Final
- Label all video clips with scene names
- Create subtitle SRT file (for accessibility)

### Step 2: Build Timeline
- Drag voiceover to primary audio track first
- Rough in all video segments to match voiceover timing
- Leave gaps for transitions

### Step 3: Visual Effects & Graphics
- Add callout boxes and text overlays
- Animate icons (scale, fade, motion) for emphasis
- Create smooth transitions between scenes (0.3–0.5s crossfades)
- Add animated counters/numbers where needed
- Color grade for consistency (same color temperature, saturation across all footage)

### Step 4: Audio Mix
- Layer background music underneath voiceover
- Voiceover: 0dB, Music: -15dB to -20dB (voiceover always dominant)
- Add subtle sound effects (transitions, button clicks)
- Create fade-in (first 1s) and fade-out (last 1s) for music

### Step 5: Review & Iterate
- Play full video with fresh ears
- Check sync between voiceover and visuals (±0.1s tolerance)
- Verify text readability at playback size
- Watch for pacing (any scene feeling too rushed or slow?)
- Do color/brightness match between cuts

### Step 6: Final Export
- Export at 1080p (1920×1080, 24fps or 30fps)
- H.264 codec, ~8-12 Mbps bitrate for YouTube
- Include markers/chapters every 30s for YouTube timestamps

## KEY VISUAL MOMENTS TO NAIL

### Moment 1: The Problem (0:05)
**Goal**: Make educators feel seen; don't be too dramatic
- Show frustrated but relatable instructor (not crying or over-the-top)
- Use split-screen: chaos vs. calm
- Music should feel tense but not scary

### Moment 2: Logo Reveal (0:22)
**Goal**: Premium, memorable entrance
- Scale logo smoothly (not too fast—3–5 seconds total)
- Add subtle shine/glow effect
- Music crescendo should peak here
- Make this the "wow" moment

### Moment 3: Real-Time Dashboard Updates (1:00)
**Goal**: Show responsiveness & live data
- Attendance list updates as students check in
- Numbers animate (0 → 25 students in 2 seconds)
- Use visual feedback (green checkmarks, confirmation pings)
- Should feel snappy and satisfying

### Moment 4: Calendar Sync (1:50)
**Goal**: Demonstrate reliability & integration
- Show both Conductor and Google Calendar side-by-side
- Sync arrows animate between them
- Text overlay: "Synced ✓" with confidence
- Should feel effortless

### Moment 5: Benefits Reveal (2:15)
**Goal**: Showcase ROI and trust
- Cards should feel substantial (not cheap/cheesy)
- Icons should be professional (not cartoon-y)
- Each stat should feel credible (cite real data if available)
- Build confidence progressively

### Moment 6: CTA (2:45)
**Goal**: Clear next action
- "Request a Demo" button should be obvious, clickable-looking
- Include multiple contact paths (web, phone, email)
- End on a high emotional note (inspiring, not desperate)
- Logo/tagline lingers for at least 2 seconds

## COMMON MISTAKES TO AVOID

❌ **Too Much Animation**: Resist the urge to animate every element. Less is more.

❌ **Voiceover Too Loud or Soft**: Normalize voiceover to -3dB, then level music underneath.

❌ **Transitions Too Fast**: Give viewers time to process. 2–3 seconds minimum per scene.

❌ **Unclear CTA**: Don't bury your call-to-action. Make it large, visible, and obvious.

❌ **Inconsistent Color Grading**: Match color temperature, saturation, and brightness across all shots.

❌ **No B-roll/Variety**: Vary visual sources—mix screenshots, icons, animations, and real footage.

❌ **Voiceover Doesn't Match Visuals**: Sync important words with key visual changes (use audio markers).

❌ **Missing Subtitles**: Always include subtitles for accessibility and silent viewers.

❌ **No Brand Consistency**: Use approved logo, colors, fonts. Create brand guidelines first.

❌ **Too Long**: Respect the 3-minute format. Every second counts; cut ruthlessly.

## DISTRIBUTION STRATEGY

### Platform-Specific Versions:

**YouTube (16:9, 1080p+)**
- Master format
- Include chapters/timestamps in description
- Add end screen with subscribe & related videos
- Pin comment with link to demo

**Social Media Variants:**

**Instagram Reels & TikTok (9:16, vertical)**
- Crop video to vertical format
- Increase font sizes for readability
- Add captions/text overlays (no sound required)
- Shorter version (60–90s) with key highlights
- Use trending audio + original audio options

**LinkedIn (1:1, square format)**
- Crop to square
- Professional tone maintained
- Include thought-leadership caption
- Link to full video and demo page

**Website/Landing Page (16:9, embedded)**
- Autoplay + muted (for auto-playback without user action)
- Fallback thumbnail image (key visual moment)
- Play button centered
- Include transcript below for SEO

**Email Campaign**
- GIF version (3–5 seconds, looping highlight)
- Linked to YouTube or landing page
- Subject line: "Watch: The Future of Classroom Management" or similar

## ANALYTICS & SUCCESS METRICS

### Track These KPIs:

**Engagement Metrics:**
- Views (total plays initiated)
- Watch time (% of video watched, average duration)
- Drop-off points (where do viewers stop watching?)
- Replay/rewatch rate

**Conversion Metrics:**
- Click-through rate to demo page
- Demo requests generated from video
- Sign-ups from viewers
- Email inquiries from viewers

**Social Metrics:**
- Shares, likes, comments
- Follower gains attributed to video
- Hashtag engagement
- Influencer/press mentions

### Analysis Process:
1. **Week 1**: Gather baseline metrics, identify any issues
2. **Week 2–4**: Optimize distribution channels, test different descriptions/titles
3. **Month 2+**: A/B test variations (thumbnails, descriptions, CTAs)
4. **Quarterly**: Compare to benchmarks, decide on refresh/sequel

## POST-LAUNCH OPTIMIZATION

**If watch-time is low (<30% average):**
- Trim opening; test with 5–10s problem statement
- Increase pacing of first 30 seconds
- A/B test different thumbnails

**If CTR is low (<1%):**
- Make CTA more prominent (larger, longer on screen)
- Add text overlay: "Request a demo →"
- Test different call-to-action buttons

**If conversions are low:**
- Landing page may be the issue (test landing page separately)
- CTA link may be broken (verify URL)
- Demo form may be too complex (simplify)

**Evergreen strategy:**
- Re-share video monthly to different audience segments
- Create short-form clips (15–30s) for new viewers
- Update with new testimonials/data quarterly
